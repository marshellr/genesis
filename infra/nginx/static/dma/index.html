DMA Statistics Module

A PHP and MariaDB workload for match-statistics analysis, kept as a read-only public showcase.

Purpose

DMA aggregates match and role-based data into a structured statistics surface. The project demonstrates how an existing stateful web workload can be isolated, routed, monitored, and documented within a larger platform.

Runtime boundary

  • Dedicated hostname and containerized PHP runtime
  • Separate MariaDB state and health behavior
  • Reverse-proxy routing through the shared ingress

Operational focus

  • Database-backed application state
  • Health monitoring and controlled deployment
  • Backup and recovery considerations for persistent data

Public access

The interactive application and all write paths are intentionally not exposed publicly. This page provides the project context without publishing administrative controls or live player data.
