Monitoring

Internal monitoring for host, containers, and services.

Prometheus, Grafana, Loki, and Uptime Kuma are available only on the internal network. Uptime checks also exercise the public Cloudflare path.

Prometheus

Collects metrics from Node Exporter, cAdvisor, and service endpoints. Alertmanager handles Prometheus alerts.

Grafana

Displays host, container, and service metrics alongside logs. The internal interface requires authentication.

Loki

Receives logs through Grafana Alloy. Logs have a 72-hour retention period.

Uptime Kuma

Checks service availability. The internal status snapshot also shows the timestamp of the latest successful local backup.

First checks during an incident

  1. Compare the availability check with a direct request through Cloudflare and an origin probe.
  2. Check Grafana and Prometheus for resource pressure, failed targets, and container restarts.
  3. Use Loki to correlate the event with short-retention logs, then confirm the affected service has recovered.
