Backup

Local backup sets and encrypted offsite snapshots.

Daily local backups contain a MariaDB dump, project files, and consistent SQLite copies. Each set has a timestamped manifest and SHA-256 checksums. The newest seven complete sets are retained.

What goes offsite

A separate nightly Restic job encrypts and uploads snapshots to offsite storage. Its pre-backup hook creates the logical MariaDB dump and consistent SQLite copies. The raw MariaDB backing directory and the duplicate local dump and archive sets are excluded.

  • The local job reserves at least 2 GiB of free space in addition to the estimated archive and staged runtime data.
  • Local files use a partial suffix until promotion. Interrupted runs are cleaned up.
  • Short-lived metrics and log stores are excluded from the offsite snapshot.

Restore verification

The restore test recovered an offsite snapshot into private staging. The MariaDB dump was imported into an isolated instance and checked against the source. The restored SQLite copies passed integrity checks.

Verify checksums before extracting a local set. Stage files away from the live tree and test database imports before applying a recovery to production.
