Architecture

How the homelab is organized.

Proxmox VE runs on operator-owned hardware in Germany. A Docker VM runs the web, database, monitoring, and logging services with Docker Compose. GitHub Pages serves the documentation independently.

Ingress and network boundaries

  • Cloudflare terminates visitor TLS. An outbound tunnel carries public requests to Nginx over HTTPS without inbound port forwarding.
  • The Nginx origin uses a Let’s Encrypt wildcard renewed with DNS-01.
  • Pi-hole resolves internal names for LAN clients. Grafana and the Uptime Kuma status interface are available only on the internal network.
  • Docker networks separate frontend, database, and monitoring traffic. MariaDB stays on the backend network.

Deployment and failure boundaries

The VM pulls versioned releases from GitHub. The public sites and monitoring share one VM. The documentation stays available independently, and encrypted offsite backups provide a recovery path if local storage is lost.
